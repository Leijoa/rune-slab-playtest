# 符文石板：第一輪友人試玩

16 關繁體中文推理遊戲。觀察符合與不符合的例子、排列符文測試猜想，最後判斷六列以通關。

## 試玩方式

先玩 10–15 分鐘，隨時停止，不要求全破。按「留下心得」，填寫後按「複製心得與紀錄」，貼給邀請者即可。無須登入，沒有自動上傳或追蹤服務。進度與心得只保存在玩家的瀏覽器。

## 本輪範圍

保留原始 16 關、PAR、反假說出題、評分與故事；新增試玩指引、星數規則說明、本機心得草稿及手動回傳摘要。保存使用獨立鍵，讀取異常時保留原始資料並提供備份，不默默覆蓋。

本輪尚未改為固定題包、重新平衡 PAR、改星數算法或擴充多人；這些需要先取得真人證據。

## 開發與驗證

`npm ci` 後執行 `npm test`。瀏覽器測試先執行 `npx playwright install chromium`，再執行 `npm run test:browser`。瀏覽器測試使用臨時本機伺服器及隔離情境，不讀寫真實玩家存檔。

GitHub Pages 從 main 的 `/docs` 發布。`PLAYTEST.md` 是主持人指引與16關盤點，內含規則答案，請勿先給玩家閱讀。
