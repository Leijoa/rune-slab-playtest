第一次玩？玩法與試玩說明

先看左右的「符合／不符合」例子，猜一條規則；在下方排出符文，按「測試」驗證猜想。可以點現有例子，修改一個地方再測。想通後，挑戰判斷六列。

建議先玩 10–15 分鐘，隨時可以停，不必全破。有卡住也可以用提示。玩完請按「留下心得」，複製文字回傳給邀請你的人。

進度與心得草稿只存在這個瀏覽器；清除網站資料或使用無痕模式可能遺失。沒有自動上傳回饋。
